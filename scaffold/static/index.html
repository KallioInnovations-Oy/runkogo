RunkoGO

Zero-dependency Go starting point for JSON APIs and microservice clusters. This scaffold is your binary — this page ships inside it, with no web fonts, no CDN, and no subresource it needs to fetch. It renders identically on an air-gapped host.

It does not ship everything a production service needs. What it promises is that every claim it makes is Enforced, a stated Convention, or explicitly Deferred — and the probes below let you check rather than trust.

// how to build the four things you actually need

Each snippet names the file it lives in, so you can read the real thing rather than a simplified version. All of it is running in this binary except the Postgres swap in step 3, which is commented out in main.go — the store implementation itself compiles and is type-checked in CI.

1 · An endpoint that fails correctly — main.go

The decision about what a client may see is made where the error is created. Handlers do not repeat it. 

// store_memory.go — the store returns domain errors, not HTTP ones.
return User{}, ErrNotFound

// main.go — mapped once, at the boundary.
func storeError(err error) error {
    switch {
    case errors.Is(err, ErrNotFound):
        return runko.NotFound("User not found").Wrap(err)
    case errors.Is(err, ErrConflict):
        return runko.Conflict("A user with this email already exists").Wrap(err)
    default:
        return err // becomes a generic 500 — never leaks the driver message
    }
}

// Every handler then ends the same way.
if err != nil {
    runko.RespondError(w, r, h.logger, storeError(err))
    return
}

Probe it above: /api/v1/users/no-such-id and the duplicate-email POST.

2 · Middleware in an order that actually holds — main.go

Root middleware wraps the router itself, so it covers 404s, 405s and redirects too. But middleware that answers a request skips everything after it — order is yours to get right. 

app.Router.Use(
    runko.Recovery(app.Logger),
    runko.BodyLimit(1<<20),
    runko.DefaultSecurityHeaders(),
    runko.RequestIDMiddleware(),
    runko.ClientIPMiddleware(app.Proxy),
    runko.Logger(app.Logger),   // after RequestID/ClientIP: they clone the
                                // request, and the router stamps the clone
    runko.RateLimit(...),        // after Logger: it answers 429s itself,
    runko.CORS(...),             // and CORS answers preflights itself
)

Put CORS first and every preflight goes unlogged. Put Logger first and you lose the matched route pattern.

3 · Swapping the database without touching a handler — store.go

Handlers depend on the UserStore interface. Pagination lives in that interface, so the SQL implementation pushes LIMIT/OFFSET into the query instead of loading the table. 

type UserStore interface {
    ListPage(ctx context.Context, limit, offset int) ([]User, int, error)
    GetByID(ctx context.Context, id string) (User, error)
    Create(ctx context.Context, name, email string) (User, error)
    Delete(ctx context.Context, id string) error
    Ping(ctx context.Context) error   // wired to /readyz
    Close() error                     // wired to OnShutdown
}

// One line in main() is the whole swap:
store, err := NewPostgresStore(ctx, "pgx", databaseURL)

store_postgres.go compiles against database/sql and is type-checked in CI — it is a reference implementation, not a commented-out guess.

4 · Surviving a rolling deploy — main.go, ordering from app.go

Readiness flips to false first, then the server keeps serving while the load balancer notices. Closing the listener immediately is what produces 502s on every deploy. 

// 1. /readyz starts failing      2. keep serving for PreStopDelay (5s)
// 3. drain in flight             4. run shutdown hooks

app.AddHealthCheck("store", 5*time.Second, store.Ping)
app.OnShutdown(func(ctx context.Context) error { return store.Close() })

Budget: PreStopDelay + ShutdownTimeout + ShutdownTimeout = 35s by default, which exceeds Kubernetes' 30s grace period. Raise the grace period or lower the timeouts — see CONV-13.

// quick start

package main

import (
    "net/http"
    runko "github.com/kallioinnovations/runkogo"
)

func main() {
    app := runko.New(runko.Options{
        ServiceName: "my-service",
    })

    // Global middleware — applied to every request.
    app.Router.Use(
        runko.Recovery(app.Logger),
        runko.BodyLimit(1<<20),
        runko.DefaultSecurityHeaders(),
        runko.RequestIDMiddleware(),
        runko.ClientIPMiddleware(app.Proxy),
        runko.Logger(app.Logger),
    )

    // Routes.
    app.Router.HandleFunc("GET /hello",
        func(w http.ResponseWriter, r *http.Request) {
            runko.JSON(w, 200, runko.Map{"msg": "hello"})
        })

    // Protected group.
    api := app.Router.Group("/api/v1", authMiddleware)
    api.HandleFunc("GET /users/{id}", getUser)

    app.Run() // Blocks until SIGINT/SIGTERM.
}

// the conventions, and what backs each one

Enforced — the framework guarantees it, with a test that fails if it breaks. Convention — you must register or do something; it says what. Deferred — deliberately out of scope, with the alternative named.
CONVENTIONS.md is the canonical list, and a test fails the build if this page, the docs, or the code drift from it.

CONV-01
Secure by default, opt in to trust. X-Forwarded-For ignored unless TrustedProxies is set; CORS denies unless listed. All XFF lines are joined, and an unparseable entry ends the walk. X-Real-IP is not read. [Enforced]
CONV-02
External input is sanitized. Request and trace IDs accept only [a-zA-Z0-9_-], max 64 chars. Bodies reject unknown fields and trailing data. [Enforced]
CONV-03
No internal detail reaches a client. Error takes only a public code and message. Health checks expose names, not error text. [Enforced (API shape) + Convention (message content)]
CONV-04
Security headers on every response. You register DefaultSecurityHeaders(); the framework guarantees it reaches 404s, 405s and redirects too. [Convention (register it) + Enforced (coverage, once registered)]
CONV-05
Dangerous config fails at startup. CORS wildcard with credentials, a bad proxy CIDR, partial TLS, empty AllowedHosts — all panic before serving. [Enforced]
CONV-06
Resources are bounded. Headers 64 KiB, body 1 MiB, responses 10 MiB. The rate limiter evicts the least recently seen client rather than refusing new ones, and buckets IPv6 by /64. [Enforced (framework-level) + Convention (per-route limits)]
CONV-07
Everything has a timeout. Server read/write/idle, per-request client timeouts, per-check health deadlines. WriteTimeout is fixed at 30s, so SSE is out. [Enforced]
CONV-08
Audit trail by default. You register Logger(); it then logs every request including unmatched ones, with the matched route pattern for aggregation. [Convention (register it) + Enforced (coverage, once registered)]
CONV-09
Sensitive data stays out of logs and URLs. No bodies, no Authorization values, no cookies. Query strings are off by default and redacted when on. [Enforced]
CONV-10
Retries are safe by default. POST is never replayed — not on 5xx, not on transport errors. The breaker is re-checked before each retry. [Enforced]
CONV-11
Rate limiting is per-instance. Across N replicas your limit is effectively N×. Cluster-wide limiting belongs at the ingress. [Convention]
CONV-12
Observability is logs, not metrics. No metrics, no spans, no pprof. Router.Mount attaches your own collector; W3C traceparent and tracestate pass through unchanged. [Deferred (metrics and spans) + Enforced (Mount, traceparent pass-through)]
CONV-13
Lifecycle is ordered; shutdown has a budget. Readiness flips before the listener closes. Shutdown hooks run even on early returns. The three phases sum — check it against your grace period. [Enforced (ordering) + Convention (the budget)]
CONV-14
CSRF for cookie-authenticated routes. Double-submit cookie, constant-time compare. Bearer APIs do not need it — browsers do not attach Authorization automatically. [Convention]
CONV-15
Errors carry their own disclosure decision. AppError binds status, public message and internal cause. Anything that is not an AppError renders as a generic 500. [Convention]

# Docker (multi-stage, scratch base)
FROM golang:1.23-alpine AS build
WORKDIR /app
COPY . .
RUN CGO_ENABLED=0 go build -o /service .

FROM scratch
COPY --from=build /service /service
EXPOSE 19100
ENTRYPOINT ["/service"]
